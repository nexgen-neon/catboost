CatBoost · Student outcome demonstration

From student information
to a pass/fail estimate.

A model that learns from example student records and estimates whether a new student is likely to pass.

Learning prototype · Artificial student data
1,000 Artificial student records in the demo
4 Inputs considered together
2 Possible outcomes: pass or fail

What information does it use?

All four inputs help the model look for patterns. It does not use just the category-based inputs.

01 / NUMBER Study hours Amount of time spent studying
02 / NUMBER Attendance Percentage of classes attended
03 / CATEGORY Learning method Classroom, online or self-study
04 / CATEGORY Internet access Yes or no
1. Learn from examples

CatBoost sees student details alongside pass/fail outcomes and learns useful patterns.

2. Improve step by step

It builds small decision trees—sets of questions about the inputs. Each new tree helps reduce the combined model’s errors.

3. Combine what it learned

For a new student, the trees’ contributions form a score that becomes an estimated pass probability and a pass/fail label.

How is CatBoost used here?

The four student inputs go into the model. The pass/fail outcome is the answer it learns to predict.

  • During training: it learns from examples with known answers.
  • During prediction: it uses the saved patterns; the new student’s answer is not supplied.
  • Why it helps: it can learn combinations of inputs instead of relying on one manually written rule, such as “more than four study hours means pass.”

CatBoost is a general prediction tool. It can also estimate prices or predict other categories when trained for those tasks.

Why is it useful for categories?

“Online,” “Classroom” and “Self Study” are groups, not quantities. CatBoost has built-in ways to learn from them.

  • Less manual preparation: declare the category columns; there is no need to create a separate input column for every category yourself.
  • No invented ranking: categories are not automatically treated as first, second and third.
  • Careful use of outcomes: when target-based category statistics are used, ordered calculations avoid using a training row’s own answer to encode that row.

Small category sets may use a simpler internal encoding. The method depends on the training settings.

Is it better than every other model? No. CatBoost is a useful starting point for data with many categories because it reduces encoding work. XGBoost and LightGBM also support categorical inputs. The best choice is the one that performs well on the same unseen test data; no comparison was run in this demo.

What does this offer?

  • A repeatable estimate: apply the same learned model to new student records.
  • Mixed inputs: use numbers and categories together.
  • More than a label: see how strongly the model favours passing.
  • A reusable model: save the trained model and load it again without retraining.

How is it checked?

The notebook separates the example data into three groups:

  • 600 training records: used to learn patterns.
  • 200 validation records: used to decide when further training stops helping.
  • 200 test records: reserved for checking predictions against known labels.

Result not yet reported: the test accuracy and confusion-matrix output have not been supplied, so this report makes no accuracy claim.

From Colab to a local computer

The workflow trains the model in Colab, saves it as student_catboost.cbm, then loads it with predict.py on Windows. The local prediction script does not need the training dataset.

Current status: the script and model were located together in src/catboost_local/. A successful local prediction output has not yet been confirmed.

What this demonstration does not establish

The records and outcomes were artificially generated using chosen assumptions and randomness. These results do not prove that a learning method or internet access causes better outcomes. Real student data and further evaluation would be needed before using this model for educational decisions.
